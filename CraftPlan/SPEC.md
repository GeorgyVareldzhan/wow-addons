# CraftPlan — как устроен аддон (версия 2.0.84)

Аддон для WoW 3.3.5a (Sirus, русский клиент). Переписан с нуля: вместо автоплана и маршрута прокачки — **стеки**, наборы рецептов, которые собираются и создаются вместе. Старая версия 0.12.22 целиком — `~/WoW-backups/CraftPlan-0.12.22-full/`.

## Данные (`CraftPlanDB`)
- `profs[проф] = { rank, max, scanned, known = { [рецепт] = true } }` — изученные рецепты из окна профессии (старый формат `recipes` переводится при входе). Пересканирование при свёрнутых разделах или фильтрах только добавляет имена; убирает — лишь полный список без фильтров.
- `bank[предмет]`, `reagentBag` — банк и хранилище материалов Sirus.
- `learn[навык][рецепт] = { req, cost, used }` — у учителя (`used` — уже выучен); `bookReq[предмет]`.
- `prospect` — журнал просеивания; `bags`, `bagsTime`, `bankTime` — см. «Сохранения для расчётов вне игры».
- `goal = { stacks = { { list = { { sk, name, n } }, add = { [предмет] = штук }, time } }, edit = номер }` — стеки (формат 0.12, переносится сам).
- `showRec`, `rawOnly`, `routeMap`, `apOpen`, `apProfName`, `apKind`, `collapsed`, `barPos`, `winPos`, `winSize`.
- При входе стираются убранные ключи: `allowChance`, `hideUseless`, `oreOff`, `nodeApplied`, `noBank`, `vendorStock`, `trainers`, `vendor`, `probe`, `map`, `mapTab`, `mapSize`, `mapPos`, `routeFold`, `learnFull`, `needShown`, `apProf`; `fish` — после переноса в FishPlan.

## Расчёт (Calc.lua)
- Порядок стеков — по самому раннему навыку изучения рецептов (`learn`, иначе жёлтый порог).
- Стеки по порядку забирают запас (`stock`, общий): каждый видит только своё. Промежуточное, которое делает рецепт ваших профессий, раскладывается до 6 уровней; лишнее от «несколько штук за раз» идёт дальше.
- Узел: `gross` нужно, `have` есть всего, `made` создать, `short` не хватает, `parents` — кто сколько просит, `kids` — из чего делается.
- Прирост (`CP.Compute`): создания — рецепты стеков (N раз) и промежуточные, которые велит создать дерево (оправы, слитки — навык в своей профессии; серые не считаются). Жадно по всем стекам сразу: на каждом шаге — создание, которое уже можно выучить по гарантированному навыку (только точные +1); жёлтое/зелёное идёт раньше оранжевых, если после него оранжевые своей профессии всё ещё успевают ниже жёлтых порогов (по порядку порогов: k-й оранжевый делается на навыке r + k − 1) — шанс жёлтых с навыком только падает, а оранжевый даёт +1 когда угодно ниже порога; иначе оранжевые (меньший жёлтый порог раньше). Среди жёлтых/зелёных — сначала те, на которые хватает материалов, затем с большим шансом. Оранжевые — точно +1 (только ниже жёлтого порога), жёлтые и зелёные — ожидаемо: шанс (серый − навык) / (серый − жёлтый). `gain[si][проф] = { o, y, g }`; округление вверх (`CP.RoundGain`: итог — сумма вверх, части вниз, недостающее — части с большей дробью). Порядок создания задаёт порядок рецептов (`CP.Entries`) в резерве запаса, «Материалах» и «Схеме»; что так и не выучить — в конце, красным «учится с N» (`CP.early`). Журнал созданий `data.log`, шаги `CP.Steps(data, filter)` (подряд идущие создания одного рецепта; серые промежуточные пропускаются), по рецепту стека — `data.span[e]` (навык с первого по последнее создание) и `data.egain[e]`. У жёлтых и зелёных ещё попытки `ym/gm`: показ «+среднее-максимум» (`CP.GainParts`, `CP.GainString`).
- `Compute()` запоминается до следующего `CP.Changed()`.
- Создание (`UNIT_SPELLCAST_SUCCEEDED`): −1 у первого по порядку стека с рецептом; полностью созданный стек (не на правке) удаляется.

## «План»
- Окно профессии перечитывается при открытии и затем не чаще раза в 2 с (`ScanTradeSkillSoon`); «изучен ли рецепт» — по указателю названий (`KnownRecipe`). Галочки «в стеке» в окне профессии и у учителя — по карте «рецепт → стеки» (`CP.StacksWith`), она строится раз после изменения.
- Сверху: «Стеки», галочки «На полосе только сырьё» и «Показать на карте зоны, где добыть».
- Плитки сеткой (мин. 200 пикс., растягиваются на ширину), одинаковой высоты; последняя — «+ Создать стек». В плитке: «Стек N», карандаш (правка), профессии «значок название навык +N», статус значком (галочка «Всё собрано», «!» «Не хватает: K мат. (N шт.)», «i» «Пусто»), сырьё 5 в ряд (до 9 + «+N»), число красное при нехватке.
- Щелчок по плитке — выделить (золотая рамка), можно несколько; ничего не выделено — «Все стеки».
- Правка (карандаш, «Редактировать», «Создать стек»): выделяется только этот стек, остальные плитки и «Создать» 60%, карандаши скрыты; в золотой строке «Правка: Стек N» под плитками — «Отмена» (откат только этого стека к копии до правки; стеки, созданные крафтом во время правки, убираются после «Сохранить»/«Отмена») и «Сохранить»; после — прежнее выделение; пустой стек при сохранении удаляется.
- Панель: «Стек N» / «Стеки 1, 2» / «Все стеки», статус (если один), «Редактировать»/«Удалить» (с вопросом). Над полосой — значок и название профессии. Полоса навыка на профессию: 0–450, заполнено до навыка (градиент), светлый отрезок прироста, после изученного максимума чёрное, золотая чёрточка. Сверху навык, итог и максимум — каждый у своей точки, рядом стоящие идут друг за другом без наложения; максимум не повторяется, если навык или итог на нём (итог на максимуме — цифра максимума зелёная). Снизу от точки навыка — части прироста цветами: оранжевым точно, жёлтым и зелёным в среднем. На плитке — одна сумма, цвет по самой ненадёжной части. Подсказка на полосе — шаги этой профессии «рецепт ×N: с → по».
- Вкладки панели: «Материалы» (таблица), «Просеивание» (только если среди выбранных стеков есть ювелирный), «Схема», «Собрать и купить» (недостающее сырьё, правый щелчок — где взять), «Где фармить».
- «Просеивание» (`DrawProspect` в UI/Plan.lua, данные — `Prospect.lua`): по каждому ювелирному стеку недостающие камни («есть/нужно» по дереву стека) и под ними руда, из которой они выпадают: «Шанс» (за одно просеивание), «Даст» (~сколько камней из руды в сумках и банке, вниз), «Есть», «Нужно руды» (чтобы закрыть нехватку). Руда, которую навык ещё не позволяет, — красным и ниже. При наведении на строку руды — кнопка «Просеять» (одна защищённая кнопка `CraftPlanProspectRowButton` на UIParent, ставится поверх строки только вне боя). «Итого» — для каждого недостающего камня руда с наибольшим шансом (сначала доступная по навыку; `CP.ProspectTopOre`), камни с одной рудой — одной строкой, руды — по самому требовательному камню (`CP.ProspectPlan`). Камни, которых хватает, — одной строкой «Хватает». Внизу «Свободные камни» — камни в сумках и банке сверх нужного всем стекам.
- Жилы — `Data/VeinData.lua` (что падает с жил 10 руд, `Tools/sirusdb.py veins`): `CP.VeinBase(ore)`, `CP.VeinsFor(ore, n)` — сколько жил на n руды, `CP.VeinSources(item)` — с каких жил падает предмет. В подсказке предмета «С жил: …» (три вероятнейшие); «Где фармить» ищет самоцветы и кристаллы и по жилам (GatherMate); на полосе у руды в углу — сколько жил обойти, в подсказке «Жил обойти: ~N».
- Шансы просеивания — `Data/ProspectData.lua` (база знаний Sirus, мир 22; генерирует `Tools/sirusdb.py [prospect|mill|all] [--json] [--refresh] [--delay N]`, кеш ответов `Tools/.cache`; `mill` пишет `Data/MillData.lua`, `veins` — `Data/VeinData.lua` (что падает с жил 10 руд: руда, камень, самоцветы, прочее, с шансами; адрес жилы `details/object/<id>`); `MillData.lua` аддон не загружает). Свой журнал заменяет шанс базы, если по руде ≥ 20 просеиваний и разница > 5 п.п. (в колонке голубым, в подсказке «Ваш шанс»).
- «Где фармить» (`CP.FarmZones`, `CP.ItemZones` в Sources.lua): недостающее сырьё выбранных стеков по зонам — жилы и травы из GatherMate (руда/камень → узлы `CP.ORE_NODES`, трава — узел с тем же названием), мобы не выше уровня+5, места сбора (не сундуки) и торговцы вашей фракции из Questie. Зоны: сначала та, где вы, потом по числу материалов и источников; до 8 зон. «На карте» — тихие метки Questie этих материалов (`WhereToGet_ShowItem(id, nil, true)`) и карта зоны. Галочка «Показать на карте зоны, где добыть» — метки всего недостающего сырья, снять — `WhereToGet_ClearAll`.
- Таблица: первый столбец «Рецепты» (галочка «Показывать рецепты» вкл.) или «Материал»; столбцы «Нужно / Есть / Создать / Не хватает» по центру; галочка — материал есть (у создаваемого галочки нет, число «Создать» голубым). Рецепт — строка с цветом рецепта, «N раз» (в правке — «- N +» и крестик «убрать из стека»); под каждым рецептом — его полное дерево до сырья с отступом и линиями. Расчёт повторяет `BuildStack` в том же порядке (стеки вне выбора резервируют своё молча): запас раздаётся по порядку строк, у общего материала (нужен нескольким) в «Есть» — сколько досталось этой ветке, в подсказке — «Всего есть N: рецепт — K, …»; у остальных — сколько есть всего. Под рецептами — «Итого»: материалы, которые встречаются в нескольких ветках, одной строкой с общими числами и под ними — из чего делаются. «Разное» — добавленное вручную. Без рецептов — простое дерево. В правке у материалов «+/-» (добавка в стек). Подсказки — только при наведении на значок (строка лишь подсвечивается; щелчок по строке рецепта — выбрать в окне профессии, правый по материалу — где взять). В строке рецепта — «275 → 290» и прирост цветами; слева «−/+» — свернуть/развернуть его дерево (`CP.coll`, по стеку, на сессию; расчёт тот же). У неизученного рецепта, которого нет у учителя, — «не у учителя» (`CP.LearnInfo`).

## «Все рецепты»
- Справа от окна, 440 пикс. Кнопки ваших профессий с навыком, поиск (крестик очистки), «Навык»: всё, что даёт навык / оранжевые / оранжевые и жёлтые / жёлтые / зелёные / все (рецепты стека видны всегда). Галочка «Только у учителя» (`db.apTrainer`): изученные и те, что есть в списке учителя (`db.learn`); скрыты рецепты-предметы (торговцы, добыча, задания) и всё, чего нет у учителя, если его список по профессии уже записан; без данных — рецепт виден.
- Сортировка — по навыку, с которого рецепт жёлтый, при равенстве — по навыку изучения (неизвестный — в конце), затем по названию. Строка своей высоты (название в 1–2 строки, материалы под ним (зазор 6) в 0–2 ряда, отступы 12 сверху и снизу; не меньше 56 пикс.; высота считается заранее скрытой строкой текста, рисуются только видимые строки): значок (бледный — не изучен), название цветом (красное — учится выше навыка) в 2 строки, материалы 3 в ряд «есть/нужно» (до 6), справа навык изучения числом (не у серых), «+N» оранжевым у оранжевых, иначе жёлтый/зелёный «+ожидаемо-максимум» столбиком, значок: галочка (изучен), книга (можно выучить), замок (рано), «?» (неизвестно). Зелёная галочка в левом верхнем углу значка — рецепт есть в каком-то стеке (в подсказке — в каком). «- N +», крестик «убрать из стека» и щелчок (правый — минус, Shift — 10) — только при стеке на правке. Подсказка (предмет; у неизученных — «Где учить»: учитель с навыком и ценой или рецепт-предмет с навыком и до 3 торговцев вашей фракции; пороги, материалы) — только при наведении на значок рецепта; на материал — подсказка предмета, как в окне профессии, и «есть / нужно», правый щелчок — где взять. У неизученного рецепта учителя — цена значками монет снизу справа, под значком состояния.

## «Схема»
- Вкладка панели стеков (после «Материалы»), по выбранным стекам или всем: колонки по глубине делят ширину панели, линии с изломом под прямым углом, иконки как в «Плане». Щелчок по создаваемому (рецепт стека или промежуточное с рецептом) — подсветить его дерево вниз до сырья, остальное 25%; повторный щелчок или по пустому месту — снять. Сырьё не кликается (правый щелчок — где взять). Наведение на создаваемое подсвечивает его дерево, пока курсор на значке (без перерисовки — меняется прозрачность).

## Полоса сверху
- Значок окна — `Trade_BlackSmithing`. Под значком % собранного по всем стекам. Значки рецептов стеков, которые можно создать сейчас (изученных; число — сколько раз; щелчок — выбрать в окне профессии), или с «На полосе только сырьё» — недостающее сырьё: под значком — % собранного (сколько есть и нужно — в подсказке) (красный → жёлтый → зелёный). У ювелира (есть «Просеивание») недостающие камни, которые даёт руда по навыку, заменяются этой рудой (с наибольшим шансом), итог по всем стекам: нужно = на крафт + на просеивание; рамка зелёная, если руды хватает; в подсказке — что закроет. Щелчок не просеивает. Справа от значка окна — кнопка «Просеивание» (`Prospect.lua`, защищённая; вне боя): число — сколько раз можно просеять, не трогая руду стеков, «!» — руда нужна стекам; при наведении столбик руды из сумок, щелчок — одно просеивание; сворачивается вместе с полосой. Подсказки к руде и камням (`Prospect.lua`): у руды — шансы просеивания или ваш журнал (`CraftPlanDB.prospect`). Стрелка — свернуть. Ctrl+перетаскивание — передвинуть. Справа от значка окна — «Дальше» (значок `Ability_Hunter_Pathfinding`): подсказка — первый шаг расчёта, щелчок — выбрать в окне профессии; при наведении столбик: следующий шаг каждого стека («Стек N»), щелчок — выбрать. Нет при «На полосе только сырьё» и свёрнутой полосе.
- «У учителя» — значок-книга с зелёной рамкой сразу за значком окна (виден и при свёрнутой полосе), только когда есть что учить: рецепты стеков, которые учатся у учителя (`db.learn`), ещё не выучены и навыка хватает (выученность — по снимку окна профессии или отметке учителя `used`; профессии без снимка не проверяются), и новый ранг профессии (навык ≥ потолок − 25, потолок < 450). Число — сколько всего, в подсказке — по профессиям. В чат (`CP.Print`): при входе одной строкой всё, что ждёт, дальше — только новое за сессию. Профессии в подсказке и чате — своим цветом (`CP.PROF_COLOR`, `CP.ProfText`). Щелчок — учителя этих профессий на карте через Questie (`WhereToGet_ShowNPCs`, только своей фракции; список — `Data/TrainerData.lua`, собирается `Tools/trainers.py` из базы Questie: титул «<Профессия> Trainer», с рангом или без, без специализаций), карта открывается на текущей зоне, если учитель есть в ней, иначе на зоне с наибольшим числом; повторный щелчок убирает метки.

## План по руде (`OrePlan.lua`)

- Вкладка панели «План по руде» (после «Просеивания»), есть, если изучено горное дело и кузнечное, ювелирное или инженерное дело (`CP.HasOrePlanTab`). Без стеков панели нет — тогда под плитками одна вкладка «План по руде». Слева вся руда: обычная — даёт навык (итог «Кузне. 275-330, Ювели. 275-310»), серая — «навыка не даст» (рецепты есть, но зелёные/серые, или план не тратит эту руду), красная — «мало навыка» (рецепты ещё недоступны); серые и красные не выбираются. Порядок: дающие навык по приросту, затем серые, затем красные. Справа план выбранной (по умолчанию — самой выгодной).
- План (`CP.OrePlan`, кеш до `CP.Changed`) — выжать навык из одной руды: только оранжевые и жёлтые создания (до середины жёлтый–серый). Рецепты — изученные и у учителя (с навыка изучения, «выучить»), всех ваших профессий, которые сводятся к этой руде: слитки, оправы, камни её просеивания (просеивание — если есть способность и навык ювелира на эту руду).
- Шаг — наибольший навык на единицу руды: руда и слитки всегда считаются рудой, камни из запаса и выпавшие попутно — даром; камень не в запасе — просеивание (5 руды, все камни по шансу из `Data/ProspectData.lua`).
- Добыча: руда в плане добывается из жил — с каждой «обычной» жилы (`CP.VeinBase`: та, где руды меньше всего) приходят и её попутные предметы (камень, самоцветы, кристаллы по шансам из `Data/VeinData.lua`) — они даром идут в план. В итоге — «добыть N (~M жил)».
- После основного плана — остатки из сумок и с добытых жил (камень, самоцветы; не выпавшее при просеивании по плану) идут в любые рецепты, пока те дают навык, в т.ч. зелёные — до серого. В плане эти строки зелёные. Без «Используя всё из сумок» в остатках только то, что дали жилы.
- «Используя всё из сумок» (по умолчанию да): запас сумок, банка и хранилища; добавляются рецепты, где кроме этой руды нужны материалы, которые уже есть (сколько хватает). Без галки — чисто руда.
- «До следующей руды» (по умолчанию нет): для каждой профессии план обрывается на навыке, с которого следующая по порядку руда (медь … титан) даёт оранжевые рецепты — выученные или доступные у учителя (`NextCap`: первая более поздняя руда с таким рецептом, навык = max(требование рецепта, текущий)). Под планом строка «Дальше: <руда> Кузне. с 300» — щелчок открывает план этой руды. Стек из плана запоминает и эту галку (`orePlan.toNext`), «Пересчитать» её учитывает.
- Галочки профессий — убрать профессию из плана. Итог: руды всего, есть, добыть; просеять и переплавить; рецепты по профессиям с количеством и навыком «с - по»; что останется из камней. «Создать стек из плана» — один стек со всеми рецептами плана (без промежуточных), переход на «Материалы». Стек запоминает руду, профессии плана (отмеченные галочками) и «Используя всё из сумок» (`st.orePlan`): на его плитке значок «Пересчитать» (`W.TEX.refresh`), а в «Материалах», когда выбран он один, — кнопка «Пересчитать»: стек собирается заново по тем же руде и профессиям, по текущим сумкам и навыку (`CP.RecalcOreStack`). Любая правка стека (сохранённая и с изменениями) снимает отметку — кнопок больше нет; списание созданного при крафте правкой не считается.
- Кнопки «Просеивание» на полосе больше нет: просеивать — «Просеять» при наведении на руду во вкладке «Просеивание».
