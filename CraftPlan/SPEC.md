# CraftPlan — как устроен аддон (версия 2.0.21)

Аддон для WoW 3.3.5a (Sirus, русский клиент). Переписан с нуля: вместо автоплана и маршрута прокачки — **стеки**, наборы рецептов, которые собираются и создаются вместе. Старая версия 0.12.22 целиком — `~/WoW-backups/CraftPlan-0.12.22-full/`.

## Файлы
| Файл | Что делает |
|---|---|
| `Data/Thresholds.lua` | `CraftPlanThresholds[навык][рецепт] = { жёлтый, серый }` — пороги цвета (из файлов клиента) |
| `Data/Recipes.lua` | `CraftPlanRouteData[навык]` — все рецепты: `"заклинание\|название\|жёлтый\|серый\|с профессией\|изделие\|штук\|материал*кол;…\|перезарядка"` |
| `Core.lua` | база `CraftPlanDB`, профессии (`CP.SKILL_ID/NAME`), пороги и цвет (`KindAt`), шанс (`Chance`), «есть» (`CP.Have` = сумки + хранилище Sirus `-4` + банк), чтение окна профессии, учителя (`db.learn`), банка; события; `CP.Changed()` — перерисовка через 0.3 с; `/cplan` |
| `Calc.lua` | рецепты из таблицы (`CP.Recipes`, `FindRec`), кто делает предмет (`Producer`, изученные в приоритете), стеки (`Goal`, `StackOrder`), дерево материалов с резервом (`Compute`, `Merge`), прирост навыка, правка (`BeginEdit/NewStack/SaveEdit/CancelEdit`, `Bump`, `AddMat`), вычитание созданного |
| `Sources.lua` | где учить рецепт: учитель (`learn`: навык, цена) или рецепт-предмет из базы Questie (перебор `ItemPointers` раз за сессию, «Префикс: рецепт» по таблице порогов), торговцы вашей фракции (`VendorsOf`), навык по подсказке предмета (`BookReq`); `CP.RecipeSource`, `CP.RecipeItem`, `CP.Money`; где искать предмет (`CP.ItemSources`: с чего добывается, мобы, торговцы, зоны) — в подсказке сырья стеков и материалов в окне CraftPlan |
| `UI/Widgets.lua` | общие виджеты: холст с пулами (`Text, Rect, Box, Area, TextButton, Button, Icon, Status, PlusMinus, SkillBar`), поле поиска с крестиком игры, галочка, выпадающий список, рамка окна |
| `UI/Window.lua` | окно `CraftPlanWindow`: вкладки «Схема \| План», «Все рецепты», размер и место (`winSize/winPos`), Esc |
| `UI/Plan.lua` | вкладка «План» |
| `UI/Schema.lua` | вкладка «Схема» |
| `UI/Recipes.lua` | окно «Все рецепты» |
| `UI/Bar.lua` | полоса сверху |
| `Hooks.lua` | «- N +» у учителя и в окне профессии, зелёная галочка слева у рецептов из стеков (подсказка — в каких), «+» у торговца, Shift+щелчок по предмету, строка в подсказке предмета |
| `WhereToGet.lua` | «где взять» через Questie (перенесено из 0.12 без изменений, `/wtg`, кнопка у миникарты) |

## Данные (`CraftPlanDB`)
- `profs[проф] = { rank, max, recipes, scanned }` — изученные рецепты из окна профессии.
- `bank[предмет]`, `reagentBag` — банк и хранилище материалов Sirus.
- `learn[навык][рецепт] = { req, cost }` — у учителя; `bookReq[предмет]`.
- `goal = { stacks = { { list = { { sk, name, n } }, add = { [предмет] = штук }, time } }, edit = номер }` — стеки (формат 0.12, переносится сам).
- `tab`, `sub`, `showRec`, `rawOnly`, `routeMap`, `apOpen`, `apProfName`, `apKind`, `collapsed`, `barPos`, `winPos`, `winSize`.
- При входе стираются убранные настройки: `allowChance`, `hideUseless`, `oreOff`, `nodeApplied`, `noBank`.

## Расчёт (Calc.lua)
- Порядок стеков — по самому раннему навыку изучения рецептов (`learn`, иначе жёлтый порог).
- Стеки по порядку забирают запас (`stock`, общий): каждый видит только своё. Промежуточное, которое делает рецепт ваших профессий, раскладывается до 6 уровней; лишнее от «несколько штук за раз» идёт дальше.
- Узел: `gross` нужно, `have` есть всего, `made` создать, `short` не хватает, `parents` — кто сколько просит, `kids` — из чего делается.
- Прирост: только оранжевые создания (до жёлтого порога, не выше максимума навыка), навык идёт по стекам по порядку; рецепт, который учится позже, — с навыка изучения.
- `Compute()` запоминается до следующего `CP.Changed()`.
- Создание (`UNIT_SPELLCAST_SUCCEEDED`): −1 у первого по порядку стека с рецептом; полностью созданный стек (не на правке) удаляется.

## «План»
- Сверху: «Стеки», галочки «На полосе только сырьё» и «Показать на карте зоны, где добыть».
- Плитки сеткой (мин. 200 пикс., растягиваются на ширину), одинаковой высоты; последняя — «+ Создать стек». В плитке: «Стек N», карандаш (правка), профессии «значок название навык +N», статус значком (галочка «Всё собрано», «!» «Не хватает: K мат. (N шт.)», «i» «Пусто»), сырьё 5 в ряд (до 9 + «+N»), число красное при нехватке.
- Щелчок по плитке — выделить (золотая рамка), можно несколько; ничего не выделено — «Все стеки».
- Правка (карандаш, «Редактировать», «Создать стек»): выделяется только этот стек, остальные плитки и «Создать» 60%, карандаши скрыты; в золотой строке «Правка: Стек N» под плитками — «Отмена» (откат к копии до правки) и «Сохранить»; после — прежнее выделение; пустой стек при сохранении удаляется.
- Панель: «Стек N» / «Стеки 1, 2» / «Все стеки», статус (если один), «Редактировать»/«Удалить» (с вопросом). Над полосой — значок и название профессии. Полоса навыка на профессию: 0–450, заполнено до навыка (градиент), светлый отрезок прироста с «+N», после изученного максимума чёрное, золотая чёрточка; подписи сверху (навык, итог, максимум; не накладываются — максимум уходит вниз).
- Вкладки панели: «Материалы» (таблица), «Собрать и купить» (недостающее сырьё, правый щелчок — где взять), «Где фармить» (пока заглушка).
- Таблица: первый столбец «Рецепты» (галочка «Показывать рецепты» вкл.) или «Материал»; столбцы «Нужно / Есть / Создать / Не хватает» по центру; галочка — хватает. Рецепт — строка с цветом рецепта, «N раз» (в правке — «- N +» и крестик «убрать из стека»); его материалы деревом с отступом и линиями; общий материал (нужен нескольким) — в разделе «Общие» полной строкой, в ветках — ссылка «название» (голубая, подчёркивание при наведении, щелчок — прокрутка) и количество: хватает этому рецепту — зелёная галочка и число, нет — «xN (ещё M)» красным; покрытое (из запаса + сколько реально можно создать — по самому дефицитному материалу ниже) раздаётся ссылкам по порядку строк; «Разное» — добавленное вручную. Без рецептов — простое дерево. В правке у материалов «+/-» (добавка в стек). Подсказки — только при наведении на значок (строка лишь подсвечивается; щелчок по строке рецепта — выбрать в окне профессии, правый по материалу — где взять).

## «Все рецепты»
- Справа от окна, 440 пикс. Кнопки ваших профессий с навыком, поиск (крестик очистки), «Навык»: всё, что даёт навык / оранжевые / оранжевые и жёлтые / жёлтые / зелёные / все (рецепты стека видны всегда).
- Строка 62 пикс.: значок (бледный — не изучен), название цветом (красное — учится выше навыка) в 2 строки, материалы 3 в ряд «есть/нужно» (до 6), справа навык изучения числом (не у серых), «+N» оранжевым у оранжевых, иначе жёлтый/зелёный «+ожидаемо-максимум» столбиком, значок: галочка (изучен), книга (можно выучить), замок (рано), «?» (неизвестно). Зелёная галочка в углу значка — рецепт есть в каком-то стеке (в подсказке — в каком). «- N +», крестик «убрать из стека» и щелчок (правый — минус, Shift — 10) — только при стеке на правке. Подсказка (предмет; у неизученных — «Где учить»: учитель с навыком и ценой или рецепт-предмет с навыком и до 3 торговцев вашей фракции; пороги, материалы) — только при наведении на значок рецепта; на материал — подсказка предмета, как в окне профессии, и «есть / нужно», правый щелчок — где взять.

## «Схема»
- Пока — по стекам (выбранным или всем): колонки по глубине, линии с изломом под прямым углом, иконки как в «Плане». Полный перенос старой схемы (рецепты профессий, фильтры, поиск, подсветка) — следующий этап.

## Полоса сверху
- Значок окна, под ним % собранного по всем стекам. Значки рецептов стеков, которые можно создать сейчас (изученных; число — сколько раз; щелчок — выбрать в окне профессии), или с «На полосе только сырьё» — недостающее сырьё: под значком — % собранного (сколько есть и нужно — в подсказке) (красный → жёлтый → зелёный). Справа от значка окна — кнопка «Просеивание» (`Prospect.lua`, перенесена из 0.12): число — сколько раз можно просеять, не трогая руду стеков, значок «!» — руда нужна стекам; при наведении столбик руды, щелчок — одно просеивание; журнал выпавшего в `CraftPlanDB.prospect`, подсказки к руде и камням. Стрелка — свернуть. Ctrl+перетаскивание — передвинуть.

## Ещё не перенесено (следующие этапы)
- Полная «Схема» из 0.12; «Где фармить» и метки на карте (галочка есть, метки пока не ставятся); подсказка «пригодится» к материалам; кнопка «Купить» у торговца; метки учителей; 
- Рыбалка — отдельным аддоном.
